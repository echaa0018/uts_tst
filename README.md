# Top 10 Anime based on the MyAnimeList website

A simple web to demonstrate Jikan API usage by displaying top 10 anime based on user ratings in the MyAnimeList website https://myanimelist.net/topanime.php . 

You can access this simple web here https://myanimelist-top-10.vercel.app .

## Data Sources

* **Jikan API:** Anime data and rankings.
* **YouTube Data API:** Official trailers.
* **TMDB API:** High-resolution background images.
